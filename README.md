# 背背 BeiBei · 语文英语背诵助手

帮你把课文真正背下来的小工具：**AI 朗读跟读 → 遮词/逐句/全文默写 → 自动出题 → 错题间隔复习**。

## 功能

- **🎧 朗读跟读**：整篇/单句朗读（Edge TTS 自然音色）、单句循环、跟读录音回放对比
- **🙈 背诵闯关**：关键词挖空（比例可调）、逐句推进（背完对照、自动标错字漏字）、全文默写
- **🎯 出题练习**：课文填空/选择/听写、单词词库（词义选择·词义拼写·听音写词）、理解性默写题库
- **🔁 错题本**：自动收集错题，按艾宾浩斯间隔（1/2/4/7/15/30 天）安排复习
- **📊 统计**：连续打卡、每日朗读/背诵/做题量、近 7 天曲线

## 内置资料

- 高中语文必背 60 篇（2025 新版）
- 高中语文理解性默写 60 篇题库（235 题）
- 高考英语 2050 核心词汇（一词一义一语境，1248 词含例句）

## 语音

- 默认 **Edge TTS**（微软朗读服务，中英文自然音色，外网可用）
- 手机系统语音（离线兜底）
- 可选：自建 GPT-SoVITS 克隆音接口（设置 → 自定义朗读接口）

## 使用

直接打开 GitHub Pages，或 `python server.py 8899` 后访问 `http://电脑IP:8899`（局域网模式：进度保存在电脑上，多设备同步）。

静态模式下进度保存在浏览器 localStorage，可通过「我的 → 导出/导入」备份。

## 数据

`data/` 目录：library.json（课文）/ vocab.json（词库）/ dictation.json（默写题库）
