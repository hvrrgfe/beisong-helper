# 背诵助手 📖

**简单 · 熟悉 · 重复** — 高考语文古诗文 + 英语词汇背诵工具

## 功能

- **📚 资料库**：浏览所有背诵资料（古诗文60篇、核心词汇2050、基础词汇700、拓展词汇370、不规则动词99）
- **🎴 闪卡背诵**：英语单词和不规则动词，点击翻转，标记认识/不认识
- **✍️ 古文背诵**：先通读熟悉，再用填空模式测试，支持挑战模式
- **📊 进度追踪**：熟悉度星级评估（0-5星），自动记录学习进度
- **💾 本地存储**：进度保存在浏览器 localStorage，无需账号

## 背诵方法

- **简单**：每次只看一张卡片/一篇诗文，不必贪多
- **熟悉**：先通读全文建立印象，再逐步遮盖测试
- **重复**：不熟的反复出现，已熟的间隔复习

## 技术

- 纯前端 HTML/CSS/JavaScript，无框架依赖
- 数据为 JSON 格式，静态文件托管
- 适配移动端和桌面端

## 数据来源

- 高考语文必背60篇（2025新版）
- 高考英语核心词汇2050（按词频排序）
- 高考英语基础词汇700（按词性排序）
- 高考英语拓展词汇370（按词性排序）
- 高考英语不规则动词约100词

## 使用

在浏览器中打开 `index.html` 即可使用。也可以部署到 GitHub Pages。
